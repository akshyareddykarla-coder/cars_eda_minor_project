**Exploratory Data Analysis on a Cars Dataset Using Python**

## Project Overview
This project focuses on analysing used-car data to understand automobile market trends, pricing patterns, and vehicle characteristics using Python.

The objective is to clean the dataset, perform statistical analysis, identify patterns and outliers, and present meaningful insights through data visualisations.

## Objectives
- Understand the structure and features of the cars dataset.
- Identify and handle missing values and duplicate records.
- Perform exploratory data analysis.
- Study relationships between car prices, manufacturing years, fuel types, and kilometres driven.
- Identify important patterns and insights through visualisations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
**Dataset:** CarDekho Used Car Dataset

**Source:** Kaggle – Car Details from Car Dekho

The dataset contains information about car brands, manufacturing years, selling prices, kilometres driven, fuel types, seller types, transmission types, and ownership.

## Project Workflow
1. Dataset collection and understanding
2. Data cleaning and preprocessing
3. Descriptive statistical analysis
4. Univariate analysis
5. Bivariate and multivariate analysis
6. Data visualisation
7. Identification of patterns and insights
8. Conclusion

## Expected Visualisations
- Car price distribution
- Most common car brands
- Fuel type distribution
- Car age versus selling price
- Kilometres driven versus selling price
- Transmission type versus selling price
- Correlation heatmap
